# Emergent  Lattice Architecture (ELA)
This repository contains the official dataset, statistical post-processing scripts, and TikZ figure generation code for **Emergent Lattice Architecture I: Foundations and Spacetime Emergence**, **Emergent Lattice Architecture II: Micro-Scale Physics, Gauges, and Interactions** and **Emergent Lattice Architecture III: Macro-Scale Cosmology, Dark Energy, and Cyclic Bounce**.
